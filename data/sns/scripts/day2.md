# Day2 台本(柱③)メニュー写真は窓際で撮るだけで変わる

- 尺: 約20秒 / 縦 9:16 / 顔出しなし / ナレーションなし
- 状態: 下書き

## 台本

| 秒 | 画面 | テロップ |
|---|---|---|
| 0-3(フック) | 暗い照明下で撮った料理写真(左)と窓際の写真(右)の比較 | メニュー写真、カメラを買う前にやること |
| 3-10 | 窓際に皿を置く手元の映像(スマホで撮影) | 答えは「窓際で撮る」。昼の自然光が入る席で撮ってみてください |
| 10-16(本編・理由1つ) | 皿を真上から撮る手元。画面に構図の枠線 | 料理の色がきれいに写ると、味の想像がしやすくなります |
| 16-20(締め) | 3つのコツの文字カード(窓際/真上/皿を拭く) | 窓際、真上から、皿のふちを拭く。保存して、次の撮影で見返してください |

- 理由は「色がきれいに写ると味が想像しやすい」の1つ。効果の数字は出さない。
- 「見た目が良い写真で注文が増える」などの効果の断定はしない。

## 撮影・制作の段取り

- 必要な素材
  - 自分で用意した料理(自宅で作ったものでよい。店の料理を使う場合は店の許可を取る)
  - 同じ料理を「照明下」と「窓際」で撮った2枚(実際に撮って比較する。加工で差をつけない)
  - 3つのコツの文字カード(自作)
- 画面に映すもの: 皿とスマホを持つ手元のみ(顔・人物は映さない)
- テロップ案: 表のとおり
- BGM: 自作またはライセンス明確なもの
- 注意: 比較写真は本当に撮った2枚を使う。実際より差が出るような補正はしない
