# Day1 台本(柱①)自分のお店の名前を検索してみる

- 尺: 約22秒 / 縦 9:16 / 顔出しなし / ナレーションなし(テロップ+BGM)
- 状態: 下書き

## 台本

| 秒 | 画面 | テロップ |
|---|---|---|
| 0-3(フック) | 検索窓に店名(ダミー)を打つ手元の画面録画 | 自分のお店の名前、スマホで検索しましたか? |
| 3-8 | 検索結果の画面(ダミー店舗でGoogleマップ枠を再現した画像) | お客さんが最初に見るのは、この画面かもしれません |
| 8-16(本編・理由1つ) | 営業時間・電話番号・写真の欄をなぞる | 営業時間、電話番号、写真。古いままだと、お店に来る前に迷われてしまいます |
| 16-22(締め) | チェックリスト画像(営業時間/電話/写真) | 今日の仕込みの合間に、1分だけ確認を。あとで見返せるよう保存してください |

- 理由は「古い情報だと来店前に迷われる」の1つだけ。「検索する人が◯割」のような数字は使わない(根拠がないため)。
- 「かもしれません」と推測形にしている。断定しない。

## 撮影・制作の段取り

- 必要な素材
  - ダミー店舗名(架空)で作った、検索結果とマップ情報の再現画像(実在の店のスクリーンショットは使わない)
  - スマホ画面録画(自分のスマホの検索窓に文字を打つ操作。画面内に実在店が映らないよう、事前に検索履歴・候補を消す)
  - チェックリスト画像(Canvaなどで自作)
- 画面に映すもの: 検索窓、再現した情報欄(営業時間/電話/写真)
- テロップ案: 上記の表のとおり。1画面あたり2行以内、大きめの文字
- BGM: 自作またはライセンス明確なもの。音量は小さめ
- 注意: 実在の店名・Googleの画面そのままの転載は避け、再現画像を使う(Googleの画面の使い方は規約を要確認)
