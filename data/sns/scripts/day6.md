# Day6 台本(柱②)売上をスプレッドシートで見える化

- 尺: 約25秒 / 縦 9:16 / 顔出しなし / ナレーションなし
- 状態: 下書き

## 台本

| 秒 | 画面 | テロップ |
|---|---|---|
| 0-3(フック) | 手書きの売上ノート(ダミー)を閉じる手元 | 売上ノート、見返していますか? |
| 3-9 | スプレッドシートに「日付」「売上」の2列を入れる画面録画(ダミー値) | 毎日つけるのは「日付」と「売上」の2つだけで十分です |
| 9-19(本編・理由1つ) | 入力後、折れ線グラフを作る操作(ダミー値) | グラフにすると、曜日ごとの波が目で見えて、仕入れや仕込みの目安にしやすくなります |
| 19-25(締め) | 2列の文字カード | 凝った表は、あとからで大丈夫。まず2列から。保存してください |

- 理由は「グラフにすると波が見えて仕入れの目安にしやすい」の1つ。
- 「売上が上がる」とは言わない。見えるようになる、までに留める。
- グラフの数値はすべてダミー。実在店の売上に見えないよう、軸の数字は非表示にするか明示的に「サンプル」と書く。

## 撮影・制作の段取り

- 必要な素材
  - ダミーの売上ノート(自作)
  - スプレッドシートの画面録画(架空の値で、2列入力→折れ線グラフ作成)
  - 文字カード
- 画面に映すもの: スプレッドシート画面。画面隅に「サンプル」の表示
- テロップ案: 表のとおり
- BGM: 自作またはライセンス明確なもの
- 注意: 録画前にアカウント名・他タブ・通知を消す
