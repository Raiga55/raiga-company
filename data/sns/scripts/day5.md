# Day5 台本(柱③)口コミ返信の型

- 尺: 約28秒 / 縦 9:16 / 顔出しなし / ナレーションなし
- 状態: 下書き
- AI要素: 下書きに使う手もある、と一言だけ(さりげなく)

## 台本

| 秒 | 画面 | テロップ |
|---|---|---|
| 0-3(フック) | スマホで口コミ通知が来るダミー画面 | 口コミ返信、毎回悩んでいませんか? |
| 3-9 | 文字カード「型は3つだけ」 | 型は3つ。①お礼 ②書かれた内容に触れる ③また来てねの一言 |
| 9-19(本編・理由1つ) | ダミーの口コミと返信例(架空)を、3色のマーカーで分解 | 内容に触れると、ちゃんと読んでくれたと伝わります |
| 19-24 | 低評価の例(架空)に、落ち着いた返信例 | きびしい口コミにも、まずお礼とお詫び。言い返さないのが基本です |
| 24-28(締め) | 小さな文字「下書きはAIに頼むのも手。最後は自分の言葉で」 | 3つの型を保存して、次の返信で使ってみてください |

- 理由は「内容に触れると読んでくれたと伝わる」の1つ。
- 返信例はすべて架空。実在の口コミ・投稿者・店は使わない。
- 低評価の返信については「基本です」と書いたが、一般的な作法であり、効果の数字は示していない。

## 撮影・制作の段取り

- 必要な素材
  - 架空の口コミ文と返信例(自作。本物の口コミを転載しない)
  - 口コミ通知風のダミー画面(自作。特定サービスのロゴを使わない)
  - 3色マーカーのハイライト画像
- 画面に映すもの: ダミー画面と文字カード
- テロップ案: 表のとおり
- BGM: 自作またはライセンス明確なもの
- 注意: 口コミの返信文面は、実際の運用では店ごとの言葉に直すよう、キャプションで一言添える
