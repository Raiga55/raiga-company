# Day3 台本(柱②)予約をスマホで見える形にする

- 尺: 約25秒 / 縦 9:16 / 顔出しなし / ナレーションなし
- 状態: 下書き

## 台本

| 秒 | 画面 | テロップ |
|---|---|---|
| 0-3(フック) | 紙の予約台帳(自作ダミー)をめくる手元 | 予約台帳、お店の外でも見られたら楽ですよね |
| 3-10 | 台帳の端に「消えた跡」や走り書きがあるダミー | 紙の台帳は書きやすい。でも、持ち出せないし、見返しにくい面もあります |
| 10-19(本編・理由1つ) | スマホでスプレッドシートの予約表(ダミーデータ)を開く画面録画 | 予約を表にしてスマホで見られると、仕込みの量を外からでも確認できます |
| 19-25(締め) | 表の項目(日付/時間/人数/名前)の文字カード | まずは「日付・時間・人数・名前」の4列から。保存して、作るときの見本に |

- 理由は「外からでも予約状況を確認できる」の1つ。
- 特定の予約サービスの名前は出さない(他社比較・宣伝になるため)。無料のスプレッドシートで紹介する。
- 個人情報(お客様の名前・電話)の扱いに触れる一言が必要かは未確認。下記確認事項に記載。

## 撮影・制作の段取り

- 必要な素材
  - ダミーの紙台帳(自作。実在客の名前は書かない)
  - ダミーデータ入りのスプレッドシート画面録画(架空の名前・時間)
  - 4列の文字カード(自作)
- 画面に映すもの: スマホのスプレッドシート画面(架空データ)。通知・アカウント名・他アプリが映り込まないよう録画前に確認
- テロップ案: 表のとおり
- BGM: 自作またはライセンス明確なもの
- 注意: 実際のお客様情報を絶対に画面へ出さない
