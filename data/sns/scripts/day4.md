# Day4 台本(柱①)ポータルサイトと自店の情報、役割が違う

- 尺: 約25秒 / 縦 9:16 / 顔出しなし / ナレーションなし
- 状態: 下書き
- 宣伝度: 軽い(末尾に一言のみ)

## 台本

| 秒 | 画面 | テロップ |
|---|---|---|
| 0-3(フック) | 「ポータルに掲載中」と書いた文字カード | ポータルに載せているから大丈夫、でしょうか |
| 3-9 | 2つの箱の図。左「ポータル=お客さんが探す場所」 | ポータルは、お客さんと出会える大事な入り口です |
| 9-19(本編・理由1つ) | 右の箱「自店の情報=自分で決められる場所」 | ただ、掲載の見せ方や条件は、運営側の都合で変わることもあります。自分で管理できる情報の置き場が、もう1つあると安心です |
| 19-25(締め) | 「Googleマップの情報」「自店のページ」の2つの文字カード | まず、無料で整えられる自店の情報から。保存して見返してください。ホームページの相談もどうぞ |

- 理由は「自分で管理できる置き場が別にあると安心」の1つ。
- ポータルを批判しない。「大事な入り口」と位置づける。手数料・順位などの具体的な話はしない(根拠が必要になるため)。
- 宣伝は最後の「ホームページの相談もどうぞ」の一言のみ。

## 撮影・制作の段取り

- 必要な素材
  - 2つの箱の図解(自作。ポータルの実名・ロゴは使わない)
  - 文字カード3枚(自作)
- 画面に映すもの: 図解のみ。画面録画は不要(文字と画像の動画)
- テロップ案: 表のとおり
- BGM: 自作またはライセンス明確なもの
- 注意: 特定ポータルのロゴ・画面を使わない
