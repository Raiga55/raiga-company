# 電話スクリプト: HP制作・DX支援(飲食店向け)

> 下書き(2026-10-06)。実際の架電はRaigaが決めて行う。エージェントは電話しない。
> 差込: `{名乗り}`(会社名で名乗るか個人名かは未決定・要確認)、`{店舗名}`。
> 料金は未確定のため、聞かれたら「要相談」。実績・導入事例・費用の数字は話さない(決まっていないため)。

## 0. かける前のルール
- **営業お断りの表示**(Googleマップ、店のSNS、HP、貼り紙、ポータルの注意書きなど)を見つけたら、**その店には連絡しない**。リストの備考欄に「営業お断り表示あり」と記録し、状態を「連絡不可」にする。
- 一度「不要」と言われた店には再度かけない(状態を「お断り」にする)。
- 連絡先はGoogleマップの公開情報から得たもの。営業目的以外に使わない。通話内容の記録は必要最小限(日時・結果・次の約束)だけ。

## 1. かける時間帯(飲食店は忙しい)
- **避ける時間帯の目安**: ランチ 11:00〜14:00、ディナー準備〜営業 17:00〜21:00(仕込みも含む)。
- **狙い目の目安**: 14:30〜16:30ごろ(アイドルタイム)。ただしこれは一般的な推測で、**店ごとの営業時間・定休日はCSVにないため要確認**。
- 月曜や週末、雨の日など、店が忙しそうな日は避ける。
- 電話に出た人が忙しそうなら、すぐ切り上げて「また改めます」と伝える。

## 2. 最初の30秒
> もしもし、お忙しいところ失礼します。{名乗り}と申します。中小企業や地域のお店のホームページ作りやデジタル化のお手伝いをしております。
> Googleマップで{店舗名}さんを拝見して、ご連絡しました。今、30秒ほどよろしいでしょうか。

- 相手が「いいですよ」→ 続ける:
> ありがとうございます。地図上で拝見したところ、お店のホームページが見当たらなかったのですが、もしご興味があれば、簡単な資料をお送りしてもよいか、お伺いしたくてお電話しました。

- 「忙しい」→「失礼しました。ご都合のよい時間帯はございますか」と聞く。無ければ切り上げる(第5節)。
- 売り込みを押し切らない。**目的は商談ではなく「資料送付の承諾」まで**。

## 3. 断られたときの返し
| 相手の反応 | 返し(押さない) |
|---|---|
| 「間に合ってます / 必要ない」 | 「承知しました。お忙しいところありがとうございました。」で終了。再度かけない |
| 「ホームページは必要ない」 | 「そうなのですね。お店の考え方を伺えてよかったです。もし今後ご入用になったときのために、お名前だけお伝えしておいてよろしいですか」(嫌がられたら終了) |
| 「今忙しい」 | 「失礼しました。改めてかけ直してもよい時間帯はございますか」 |
| 「費用はいくら?」 | 「内容によって変わりますので、料金は要相談となっております。まずは資料でご確認いただけます」(数字は言わない) |
| 「Instagramがあるから」 | 「素敵ですね。Instagramと一緒に使える形もありますので、資料だけでもいかがでしょうか」(押さない) |
| 「営業はお断り」 | 「失礼しました。以後ご連絡いたしません」で終了。リストに記録 |

## 4. 資料送付の承諾を取る流れ
1. 「簡単な資料をお送りしてもよろしいでしょうか。見ていただいて、必要なければそのままで大丈夫です」
2. 承諾 → 送付方法を聞く(メール / LINE / FAX / 郵送 など)。**相手が選ぶ**。
3. 送付先を復唱確認。「担当者様のお名前は」と、聞いてよければ聞く(無理に聞かない)。
4. 「送付後に、こちらから催促の連絡はいたしません。ご興味があればご連絡ください」と伝える(連絡してよいと言われた場合のみ、再連絡の時期を決める)。
5. 資料(提案書)は作成後、Raigaが内容を確認してから送る。実績・費用の数字は載せない。

## 5. 切り上げ方
> お忙しいところ、お時間をいただきありがとうございました。失礼いたします。

- 相手が切るまで待つ必要はないが、こちらから先に早口で切らない。
- 通話後、すぐに記録: 日時 / 出た人 / 結果(承諾・不在・お断り・営業お断り) / 次の約束。
